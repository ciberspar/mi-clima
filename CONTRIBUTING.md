# 🤝 Guía de Contribución - Clima G

¡Hola! Qué alegría que quieras sumar mejoras a **Clima G**. Para mantener el proyecto ordenado, rápido y funcional, seguí estos simples pasos:

## 🚀 Cómo empezar
1. Hacé un *Fork* del repositorio [ciberspar/mi-clima](https://github.com/ciberspar/mi-clima).
2. Cloná tu repositorio modificado.
3. Creá una rama para tu nueva característica (`git checkout -b feature/nueva-mejora`).

## 🛠️ Reglas del Código
* Mantené la estructura limpia y sin frameworks pesados (Vanilla JS y CSS puro).
* Asegurate de que los Service Workers y la PWA sigan funcionando de forma offline.
* Probá tus cambios antes de enviar el *Pull Request*.

¡Gracias por colaborar con el Imperio de Baco y el clima en vivo! 🐢☁️
