# 🔒 Política de Seguridad

Tomamos la seguridad de **Clima G** y de sus notificaciones push muy en serio.

## 🛡️ Versiones Soportadas
Actualmente, solo la rama principal (*main*) recibe actualizaciones de seguridad y parches en las GitHub Actions.

## 🚨 Reportar una vulnerabilidad
Si encontrás algún fallo de seguridad, exposición de credenciales (como tokens o secretos VAPID) o problemas en el Service Worker, por favor reportalo de forma privada o abrénos un aviso para solucionarlo inmediatamente de forma táctica.
