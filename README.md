## 🌤️ Clima G - Aplicación del Tiempo en Vivo

**Clima G** es una aplicación web progresiva (PWA) moderna, ligera y minimalista para consultar el pronóstico del tiempo en tiempo real. Está diseñada para ofrecer una experiencia rápida, fluida y con un diseño adaptable tanto en dispositivos móviles como de escritorio.

🔗 **Sitio web:** [Accede a Clima G en línea](https://ciberspar.github.io/mi-clima/)

---

## ✨ Características Principales

* **Geolocalización GPS:** Obtiene automáticamente el clima de tu posición actual al otorgar permisos en el navegador.
* **Buscador y Favoritos:** Permite buscar cualquier ciudad del mundo mediante la API de geocodificación o seleccionar rápidamente ubicaciones preconfiguradas.
* **Pronóstico por Horas:** Visualiza un desglose hora a hora intercambiando dinámicamente entre **Temperatura**, **Probabilidad de Lluvia** y **Velocidad del Viento**.
* **Pronóstico Extendido:** Consulta las condiciones meteorológicas y el rango de temperaturas para los próximos días.
* **Alertas de Precipitación:** Avisos rápidos integrados sobre posibles lluvias o condiciones climáticas adversas en el día.
* **Modo Oscuro Automático:** Se adapta de forma nativa a las preferencias de sistema de tu dispositivo (Dark Mode / Light Mode).
* **Contador de Visitas:** Integración con GoatCounter para llevar la métrica de visitas únicas de la plataforma.

---

## 🛠️ Tecnologías Utilizadas

* **HTML5 / CSS3:** Estructura limpia y diseño moderno basado en variables CSS (`:root`) optimizado para rendimiento.
* **JavaScript (Vanilla):** Lógica del cliente sin dependencias pesadas ni frameworks externos.
* **Open-Meteo API:** Proveedor de datos meteorológicos y geocodificación en tiempo real de alta precisión y sin necesidad de claves de API (API Keys) obligatorias.
* **OpenStreetMap (Nominatim):** Geocodificación inversa para la autodetección del nombre de la localidad.
* **GitHub Pages:** Alojamiento y despliegue continuo del sitio web.
